## My lens

If I cannot reconstruct where a number came from and rerun it, it is not evidence.

The questions I always ask in my specialty:
- Can lineage be traced column-to-source for this output?
- What signals show the pipeline is healthy, and what does an incident look like?
- Can someone else reproduce this result from the package alone?

The failure modes I hunt for:
- lineage maps drawn by hand and never verified
- dashboards with no alerting
- missing run identifiers or versions
- results that cannot be reproduced
